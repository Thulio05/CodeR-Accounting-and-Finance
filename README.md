# CodeR – Accounting & Finance

Este repositório contém projetos desenvolvidos em **R** voltados à contabilidade e finanças para a disciplina da UPE.  
Nele, estão presentes análises de índices financeiros, comparações entre empresas e setores, além de métricas de liquidez e saúde financeira.

---

## Sobre o Projeto

O objetivo é aplicar ferramentas de análise de dados em R para gerar insights financeiros:  
- cálculo de índices de liquidez;  
- estudo comparativo entre empresas de diferentes setores;  
- análise de performance e risco;  
- visualização de dados para suporte à tomada de decisão.

---

## Tecnologias e Ferramentas Utilizadas

- **R** — linguagem principal  
- RStudio — ambiente de desenvolvimento  
- Pacotes comuns para manipulação de dados  
- Gráficos e visualizações para representar setores e índices
